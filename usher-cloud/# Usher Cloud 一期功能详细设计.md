

# Usher Cloud 一期功能详细设计

## 6.1 首页 / 工作台

### 界面布局

- 左侧深色导航侧栏 200px
- 右侧浅色主内容区

### 界面元素

#### 左侧导航侧栏

- 应用 Logo - 始终展示
- 场景导航项：首页 / 活动页 / Banner / 设计工具
- 工具导航项：我的任务
- P2 预留：页面快改 / 控制台原型稿 (置灰 + 敬请期待)
- 底部用户区：头像 + 设置

#### 欢迎区 / Brief 输入框

- 主标题 + 副标题
- 文本输入框
- 智能场景识别
- "开始生成" 按钮

#### 场景卡片区

- 官网活动页卡片: Code Review 标签
- 官网首页 Banner 卡片：自动发布标签
- 市场部设计工具卡片：导出文件标签
- 每卡：图标 + 标题 + 描述 + 交付标签

#### 最近任务区

- 任务名称
- 类型标签
- 状态标签：处理中 / 已完成 / 失败
- 相对时间
- 操作按钮：继续编辑 / 查看详情 / 重新生成

### 操作流程

- 方式 A: Brief 输入→场景识别→跳转
- 方式 B: 卡片点击→跳转场景
- 方式 C: 任务行→继续编辑

### 状态说明

- 加载态：骨架屏
- 空态：引导提示
- 场景识别失败：红色提示
- 任务处理中：旋转图标 + 蓝色标签
- 任务完成：绿色标签
- 任务失败：红色标签 + 重新生成
- 网络断开：全局提示条

## 6.2 官网活动页

### 界面布局

- 面包屑：官网活动页 > 创建活动页
- 区块 1: 套餐配置
- 区块 2: 页面生成
- 区块 3: 摘要与确认

### 区块 1: 套餐配置

- 卡片标题 + 导入 Excel 链接
- 可编辑表格 - 14 个字段
  - 计费小类 ID: 下拉选择 必填
  - CPU: 数字 必填 >=1
  - 内存：数字 必填 >=1
  - 系统盘：数字 必填 >=20
  - 峰值带宽：数字 必填 >=1
  - 月流量包：数字 必填 >=1
  - 地域 / 可用区：下拉 必填
  - 付费方式：下拉 必填
  - 时长：数字 必填 1-36
  - 原价续费：下拉 可选
  - 促销策略：文本 可选 <=50 字
  - 折扣：数字 可选 0-100
  - 月原价：数字 必填 >=0
  - 月付促销价：数字 必填 >=0
- 添加行 / 删除行 (二次确认)
- 批量导入 Excel
  - 选择文件→解析→校验→确认导入→错误报告
- 校验规则
  - 必填字段完整
  - CPU / 内存比例关联
  - 促销价 <= 原价
  - 折扣自动计算
  - 重复计费小类检测

### 区块 2: 页面生成

#### 左列：模板选择

- 4 个模板卡片：简洁商务 / 品牌促销 / 新品发布 / 行业展会
- 悬停上浮 + 选中蓝框

#### 右列: AI 输入

- 大文本域
- 附件上传：最多 5 张 <=10MB
- 缩略图预览 + 删除

### 区块 3: 摘要与确认

- 套餐汇总
- 模板信息
- 创建活动页按钮
  - 二次确认弹窗
  - 加载态 + 进度条
  - 成功→跳转编辑器
  - 失败→toast + 原因

### 完整操作流程

- 填写套餐配置 (逐行 / 导入 Excel)
- 选择模板 & AI 输入 (可交叉，无顺序)
- 确认创建 (写入 DB+AI 生成)
- 跳转编辑器

### 状态说明

- 表格空态：单行空白行引导
- 校验失败：红框 + 提示
- 行重复：黄底 + 警告
- 导入失败：弹窗 + 错误 CSV
- 生成中：进度条 0-100%
- 生成成功：跳转编辑器
- 生成失败: toast + 重试
- 数据冲突：弹窗提示刷新

### 所见即所得编辑器

- 左侧预览区: iframe / 同屏
- 右侧对话区: AI 修改指令
- 操作栏：保存草稿 / 查看代码 / 提交 CodeReview
- CodeReview: 填写备注→创建 MR→返回链接

## 6.3 官网首页 Banner

### 界面布局

- 面包屑：官网首页 Banner > 生成 Banner
- 区块 1: 描述 Banner 要求
- 区块 2: 候选方案
- 区块 3: 预览与发布

### 区块 1: 描述 Banner 要求

- 大文本框
- 附件上传 (参考图)
- 生成方案按钮 (输入不为空可点击)

### 区块 2: 候选方案

- 横向排列 2-4 个
- 悬停态：上浮
- 选中态：蓝框 +✅标记
- 预览区同步切换
- 重新生成

### 区块 3: 预览与发布

- 大图预览 1440x480
- 在线调整入口
- 发布到官网：绿色按钮
- 发布记录链接

### 发布流程

- 二次确认弹窗
- 发布中 (进度提示)
- 成功 toast + 查看官网链接
- 失败 toast + 重试

### 轻量编辑器

- 预览区保持
- 属性编辑面板：主文案 / 副文案 / 按钮文字 / 背景色 / 背景图
- 实时刷新
- 保存版本

### 版本记录

- 展示：缩略图 + 时间 + 发布人 + 当前标记
- 回滚：二次确认→设置当前→重新发布
- 存储上限: 30 个版本

### 状态说明

- 空输入：生成置灰 + 占位
- 生成中：骨架屏 3 卡
- 生成完成：默认无选中
- 生成失败: toast + 重试
- 无候选：提示调整描述
- 选中方案：预览更新
- 发布中 / 成功 / 失败

## 6.4 市场部设计工具

### 界面布局

- 面包屑：市场部设计工具 > 新建设计
- 区块 1: 选择物料类型
- 区块 2: 配置内容
- 区块 3: AI 确认
- 区块 4: 预览与导出

### 区块 1: 选择物料类型

- 展板 - 80x180cm
- 易拉宝 / X 展架 - 60x160cm
- 宣传页 / DM 单 - A4 竖版
- 类型切换→尺寸联动
- 未选择不可继续

### 区块 2: 配置内容

#### 左列

- 尺寸下拉：联动物料类型 + 自定义
- 风格标签：多选按钮组 (科技感 / 简约 / 活泼 / 商务) 最多 2 个
- 素材上传: Logo + 产品图 最多 3 张 <=5MB

#### 跨列文案表单

- 主标题：必填 <=20 字
- 副标题：可选 <=30 字
- 正文卖点：必填 <=200 字
- 活动时间 / 地点：可选 <=50 字
- 联系方式：可选 <=50 字
- 校验：必填红色 * 标记

### 区块 3: AI 确认

- 对话式澄清 最多 3 轮
- 典型问题
  - 素材缺失: Logo 占位确认
  - 文案优化：建议替换确认
  - 风格确认：自动匹配确认
  - 信息缺失：补充引导
  - 尺寸确认：确认 / 修改
- 交互：单项选择 / 确认
- 跳过确认：二次弹窗
- 开始生成按钮：全确认后可点击

### 区块 4: 预览与导出

#### 画布预览

- 画布预览：等比例缩放

#### 画布编辑器

- 点击选中：虚线框 + 控制点
- 浮动工具条：字号 / 颜色 / 加粗 / 对齐
- 拖拽移动
- 缩放控制点
- 双击文本编辑
- 右键菜单：置顶层 / 复制 / 删除
- 撤销 / 重做: Ctrl+Z/Y

#### 导出

- PNG: 72dpi/150dpi/300dpi
- PDF: 出血线 / 裁切线 / CMYK
- 弹窗选择→进度→下载

### 完整操作流程

- 选物料类型→联动尺寸
- 配置内容 (尺寸 / 风格 / 素材 / 文案)
- AI 澄清 (1-3 轮确认)
- 等待生成 (进度 + 骨架屏)
- 编辑 (浮动工具条 / 对话)
- 导出 (PNG/PDF + 参数)

### 状态说明

- 物料未选：类型引导
- 风格未选: AI 自动判断
- 澄清进行中：绿色进度指示器
- 跳过确认：二次弹窗
- 生成中：骨架屏 + 流式进度
- 编辑无选中：浮动工具条隐藏
- 选中图层：选中框 + 工具条
- 导出中 / 成功 / 失败

### 模板库兜底

- 各物料类型 5-10 个模板
- 人工预制一期
- 不满意→选模板替换
