# Usher Cloud 一期产品设计

**产品名称：Usher Cloud（托管版）**
它是现有 Usher 的云端托管分支，不替代现有 Usher。底层复用现有能力，产品入口、交互方式和目标用户独立设计。

[toc]

## 1. 产品定位

**Usher Cloud 面向非研发用户为主，提供零本地配置的前端页面生产、修改和原型生成能力。**

| 产品        | 主要用户                       | 产品形态                         |
| ----------- | ------------------------------ | -------------------------------- |
| 现有 Usher  | 专业研发                       | 本地开发工具与 Agent             |
| Usher Cloud | 非研发用户为主，也支持研发协同 | 浏览器访问、服务端执行、固定场景 |

用户不需要理解 Git、代码仓库、分支、本地环境和模型配置，只需要：

1. 选择场景；
2. 描述需求或选择页面元素；
3. 查看 AI 生成结果；
4. 持续调整；
5. 完成提交、发布或分享。

------

## 2. User Story



```
选择场景
   ↓
输入需求、配置或打开目标页面
   ↓
AI 在服务端生成或修改
   ↓
实时刷新预览
   ↓
用户通过聊天或所见即所得继续调整
   ↓
得到最终结果
   ├── 页面快改：提交 Code Review
   ├── 官网活动页：提交 Code Review
   ├── 首页 Banner：直接发布
   └── 控制台原型稿：自动保存并分享链接
```





### 核心体验

用户只负责说明“想要什么”和确认“结果是否符合预期”。
Usher Cloud 负责找到对应项目、执行修改、生成预览，并进入对应的后续流程。

# 5. 首页 / 工作台

![image-20260728115727571](/Users/wer/Documents/GitHub/UDocs/U-design/content/images/Skeleton/image-20260728115727571.png)

*图：首页提供四类场景的快捷入口，并通过“全部 / 处理中 / 已完成”管理用户任务。*

一期首页只展示三种任务状态：

| 状态   | 含义                                             |
| ------ | ------------------------------------------------ |
| 处理中 | AI 正在生成，或用户仍在调整                      |
| 已完成 | 已提交 Code Review、已发布，或原型已生成可用链接 |
| 失败   | 生成、构建、提交或发布失败                       |

“已完成”只表示用户侧操作完成，不区分后续是否还需要研发 Review 或人工发布。

# 6. 场景一：页面快改

## 6.1 一期支持范围

| 类型   | 站点             |
| ------ | ---------------- |
| 官网   | 官网（国内站）   |
| 控制台 | 控制台（主渠道） |

一期页面中不展示海外官网、SurferCloud 和其他控制台渠道。

## 6.2 用户流程



```
选择站点
   ↓
输入页面 URL
   ↓
加载真实页面预览
   ↓
鼠标选择页面元素
   ↓
点击“发送到对话”
   ↓
聊天窗口生成元素引用记录
   ↓
用户补充修改提示词
   ↓
AI 修改并实时刷新预览
   ↓
继续选择元素和调整
   ↓
完成并提交 Code Review
```





## 6.3 页面线框图

![image-20260728115754245](/Users/wer/Documents/GitHub/UDocs/U-design/content/images/Skeleton/image-20260728115754245.png)

*图：左侧为 AI 对话，中间为页面实时预览，右侧提供“查看代码变更”和“完成并提交 Code Review”。*

## 6.4 核心功能

| 功能         | 说明                                         |
| ------------ | -------------------------------------------- |
| 页面加载     | 根据 URL 打开对应站点页面                    |
| 元素选择     | 鼠标悬停高亮，点击后进入选中状态             |
| 发送到对话   | 用户确认后，将元素位置和内容发送到聊天窗口   |
| 元素引用记录 | 聊天窗口保留已引用元素，用户可继续补充提示词 |
| AI 修改      | 根据元素上下文和提示词修改代码               |
| 实时预览     | 修改成功后自动刷新页面                       |
| 查看代码变更 | 查看本次代码 Diff                            |
| 完成并提交   | 提交代码并生成 Code Review 记录              |

一期由研发人工完成 Code Review 和发布。

# 7. 场景二：创建 / 修改官网活动页

## 7.1 用户流程



```
填写活动套餐配置
   ↓
选择是否使用页面模板
   ├── 不使用模板
   └── 使用模板 → 选择模板
   ↓
在 AI 输入框补充页面要求，可粘贴链接或上传附件
   ↓
点击“创建活动页”
   ↓
后台写入活动套餐数据
   ↓
前端生成活动页
   ↓
进入所见即所得编辑器继续调整
   ↓
完成并提交 Code Review
```





## 7.2 活动套餐配置

活动套餐支持添加多行，每一行对应一个套餐或地域组合。

| 表单项        | 说明                     |
| ------------- | ------------------------ |
| 计费小类 ID   | 对应产品或套餐的计费标识 |
| CPU           | CPU 核数                 |
| 内存          | 内存规格                 |
| 系统盘        | 系统盘容量               |
| 峰值带宽      | 带宽规格                 |
| 月流量包      | 月流量额度               |
| 地域 / 可用区 | 套餐可用地域             |
| 付费方式      | 例如月付                 |
| 时长          | 购买周期                 |
| 原价续费      | 是否按原价续费           |
| 促销策略      | 例如折扣                 |
| 折扣（%）     | 折扣比例                 |
| 月原价        | 套餐月原价               |
| 月付促销价    | 折扣后的月付价格         |

## 7.3 创建态线框图

![image-20260728115814108](/Users/wer/Documents/GitHub/UDocs/U-design/content/images/Skeleton/image-20260728115814108.png)

*图：左侧填写活动套餐配置、选择可选模板并输入 AI 页面要求；中间实时预览；右侧进行所见即所得调整。*

## 7.4 生成后编辑态

活动页生成后进入与“页面快改”一致的所见即所得编辑器：



```
选择页面元素
   ↓
点击“发送到对话”
   ↓
补充修改提示词
   ↓
AI 修改
   ↓
实时刷新活动页预览

查看代码变更
   ↓
完成并提交 Code Review

```
活动套餐配置
   ↓
生成套餐数据并写入数据库
   ↓
返回活动及套餐标识
   ↓
模板（可选）+ AI 页面要求
   ↓
生成活动页代码
   ↓

# 9. 场景四：控制台需求原型稿

## 9.1 产品结构

用户进入“控制台原型稿”后，可以：

1. 从历史原型列表选择已有原型继续编辑；
2. 点击“新建原型”创建新的原型；
3. 对原型进行所见即所得修改或添加标注；
4. 分享当前原型链接。

不再区分“从零生成”和“基于现有页面修改”。是否参考已有页面，由用户在 AI 输入框中提供链接或截图决定。

## 9.2 用户流程



```
进入我的原型
   ↓
选择已有原型，或点击“新建原型”
   ↓
在 AI 输入框描述需求
   ↓
可粘贴原页面链接或上传截图等附件
   ↓
AI 生成或修改原型
   ↓
预览立即更新并自动保存
   ↓
继续修改、添加标注或分享链接
```





## 9.3 页面线框图

![image-20260728115851972](/Users/wer/Documents/GitHub/UDocs/U-design/content/images/Skeleton/image-20260728115851972.png)

*图：左侧为历史原型列表，中间为实时预览，右侧支持 AI 修改、标注和分享链接。*

## 9.4 核心功能

| 功能           | 说明                                 |
| -------------- | ------------------------------------ |
| 历史原型列表   | 展示当前用户创建过的原型             |
| 新建原型       | 创建新的控制台原型                   |
| AI 输入        | 一个输入框支持提示词、页面链接和附件 |
| 所见即所得修改 | 点击原型元素后提出修改要求           |
| 在线标注       | 产品、设计和研发可在原型上添加标注   |
| 自动保存       | 每次修改后立即保存并生效             |
| 分享链接       | 复制可访问的原型链接                 |

原型场景不设置“完成”操作。

# 11. 一期范围

## 一期支持

| 模块         | 能力                                                         |
| ------------ | ------------------------------------------------------------ |
| 工作台       | 四类场景入口、我的任务、处理中/已完成/失败                   |
| 页面快改     | 官网（国内站）、控制台（主渠道）、元素选择、聊天修改、实时预览、Code Review |
| 官网活动页   | 套餐配置、可选模板、AI 输入与附件、数据入库、页面生成、在线修改、Code Review |
| 首页 Banner  | AI 输入与附件、多候选生成、在线调整、自动发布、版本记录      |
| 控制台原型稿 | 历史列表、新建、在线修改、标注、自动保存、分享链接           |
| 云端执行     | 仓库、模型、运行环境和执行过程由服务端统一管理               |
| 权限控制     | 根据用户身份限制可操作站点和发布权限                         |

## 一期不展示或不支持

| 内容               | 一期处理             |
| ------------------ | -------------------- |
| 海外官网           | 不展示入口           |
| SurferCloud        | 不展示入口           |
| 其他控制台渠道     | 不展示入口           |
| 页面快改自动发布   | 暂由研发人工完成     |
| 活动页自动发布     | 暂由研发人工完成     |
| 复杂业务逻辑开发   | 提示超出当前支持范围 |
| 未接入的站点和仓库 | 提示超出当前支持范围 |
